# Tienda Web — Ferretería CMA

Catálogo digital público de la Ferretería CMA. Los productos se sincronizan desde el sistema POS y se muestran en la tienda pública, con cotización directa por WhatsApp.

## 🛠️ Tecnologías

| Capa | Tecnologías |
|---|---|
| **Backend** | Laravel 12 · PHP 8.2 · PostgreSQL · Redis |
| **Frontend** | React 18 · Inertia.js · Vite · Tailwind CSS |
| **Comunicación cliente** | WhatsApp (`wa.me`) |
| **Despliegue** | Docker + Dokploy (Nginx + PHP-FPM) |
